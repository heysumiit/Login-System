# Login System

### User Authentication Interface | Sign In | Sign Up | Forgot Password

A user-friendly Login System project designed to provide a simple interface for user authentication. It includes sign-in, sign-up, and forgot-password pages with input validation to improve usability and help ensure accurate user input.

---

## About

The Login System provides an interface for users to enter their credentials and navigate through authentication-related pages.

The project includes multiple sign-in and sign-up page designs, along with a forgot-password page.

## Features

* User-friendly authentication interface
* Sign-in page for entering user credentials
* Sign-up page for user registration
* Additional sign-in and sign-up page designs
* Forgot-password page
* Input validation to improve data entry accuracy
* Simple and organized page structure

## Pages Included

| Page               | Description                 |
| ------------------ | --------------------------- |
| SignIn Page        | User login interface        |
| SignIn Second Page | Alternative sign-in page    |
| SignUp Page        | User registration interface |
| SignUp Second Page | Alternative sign-up page    |
| Forgot Page        | Forgot-password interface   |
